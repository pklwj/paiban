# 影像科排班表

一个放在文件夹里、双击就能用的排班工具。不用装软件、不用联网、不上传数据。

面向科室周排班的实际写法设计：格子里就是 `上下审 XCM`、`休/DR4`、`上写/值` 这样的自由文本，程序按关键词统计人数，再导出成能直接打印的 Excel。

## 快速开始

1. 下载或克隆本仓库
2. 双击 `index.html`（推荐 Chrome / Edge）
3. 点「更多 → 清空排班」，按自己的科室重填

仓库里的示例数据是**脱敏占位**（`医生01`～`医生20`、`护士01`～`护士05`、`技师01`～`技师18`），排版和真实数据一致，可以直接照着改。

## 主要功能

**排班编辑**

- 单击选中，再点一次（或双击）进入编辑，浮层里有一排常用写法、岗位、标记按钮
- 拖动框选一块区域，`Shift` + 方向键扩选
- `Ctrl+C` / `Ctrl+V` 整块复制粘贴，格式是制表符，**可以直接和 Excel 互相粘贴**
- 支持撤销 / 重做，最多 80 步
- 按医生 / 护士 / 技师分组显示，导出时仍是一张连续表

**人数统计**

- 自动识别格子里的「审」「写」，按上午 / 下午分别计数
- 默认只统计医生，可在「设置」里改成全体
- 表底写法两种都认：全是单位数用 `5587`，出现两位数用 `3/3/10/8`
- 与实际不符会标红，点「校验」可逐条定位

**导出 Excel**

- A4 纵向、整张缩到一页
- 合并标题、冻结窗格、边框、隔行底色、周末不做特殊处理
- 格子里的标记（`▲ ● ★ ※`）自动变成红色上标
- 姓名整列加粗

**数据保存**

- 默认存在浏览器本地（关掉再开还在，但换电脑就没有）
- 想把数据带走：`更多 → 新建数据文件`，存到 U 盘上的 `排班数据.json`，之后每次改动自动写回；换电脑时点右下角「数据存本机」选中这个文件即可
- 也可以 `更多 → 导出 JSON 备份` 手动留底

## 键盘

| 操作 | 说明 |
| --- | --- |
| `↑ ↓ ← →` | 移动选中格 |
| `Shift` + 方向键 | 扩选区域 |
| `Enter` | 编辑当前格 |
| `Tab` | 确认并右移 |
| `Ctrl + C` / `Ctrl + V` | 复制 / 粘贴选区 |
| `Ctrl + D` | 把上一行内容填下来 |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做 |
| `Ctrl + S` | 导出 Excel |
| `Esc` | 取消编辑或框选 |

## 目录

```
index.html            入口，双击打开
css/style.css         样式
js/core.js            纯逻辑：解析格子、统计人数、校验（无 DOM 依赖）
js/seed.js            示例数据（脱敏）
js/export.js          Excel 导出，版式与配色都在这里
js/app.js             界面与交互
vendor/exceljs.min.js 生成 xlsx 用，已内置，离线可用
tests/run.js          回归测试
tests/run.cmd         Windows 下双击跑测试
```

## 测试

```bash
node tests/run.js        # 全部
node tests/run.js core   # 只跑纯逻辑
```

测试会启动无头 Chrome 跑真实交互，需要本机装有 Chrome 或 Edge。也可以用 `CHROME` 环境变量指定浏览器路径。

## 说明

- 导出依赖 [ExcelJS](https://github.com/exceljs/exceljs)（MIT），已随仓库内置，保证离线可用
- 直接读写 U 盘上的数据文件用到 File System Access API，目前只有 Chromium 系浏览器支持；其他浏览器会退化成「导出 JSON / 导入 JSON」
- 建议一个文件只在一台电脑上编辑。多个窗口同时打开同一个数据文件，后保存的会覆盖先保存的

## 接手这个项目

改动前先看 [AGENTS.md](AGENTS.md)：里面写了业务规则、导出规格，以及几条「明确要求删掉、不要加回来」的决定。
